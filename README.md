# ☉ Солнечная система · интерактивная 3D карта

Интерактивная модель Солнечной системы на Three.js: живое Солнце с короной и протуберанцами, восемь планет со спутниками, кольца Сатурна из частиц, пояс астероидов, пояс Койпера и комета с ионным хвостом.

**Живая версия:** https://razorbladee.github.io/solar-system-3d/

---

## Что внутри

### Солнце
| Слой | Реализация |
|---|---|
| Фотосфера | GLSL simplex noise, 5 октав fBm, три масштаба грануляции дрейфуют с разной скоростью |
| Пятна | Отдельный слой шума, затемняющий поверхность до 72 % |
| Потемнение к краю | `pow(dot(N, V), 0.42)` по нормали к камере |
| Хромосфера и корона | Три вложенные fresnel-оболочки с независимым мерцанием |
| Протуберанцы | 2 600 частиц, дуга целиком считается в вершинном шейдере: `sin(t·π)` по высоте плюс касательный снос |
| Гало | Additive-спрайт с медленной пульсацией |

### Поверхности планет
Текстуры генерируются процедурно на канвасе при загрузке. Шум считается **на сфере в 3D**, а не по UV, поэтому на экваторе и полюсах нет швов.

- **Земля:** материки по порогу fBm, батиметрия по глубине, широтные пояса (пустыни, тайга, ледники), отдельный слой облаков как alpha-карта
- **Юпитер:** зональные пояса `sin(lat · 16.5 + turb)` плюс Большое Красное Пятно как эллипс в координатах lat/lon
- **Нептун:** Большое Тёмное Пятно и перистые полосы
- **Марс, Меркурий, Луна:** ridged-шум как поле кратеров, полярные шапки, лунные моря
- **Венера:** вытянутые по широте вихри сернокислотной облачности

Если сеть доступна, реальные NASA-карты Земли и Луны подгружаются поверх процедурных.

### Кольца Сатурна
26 000 частиц в экваториальной плоскости планеты. Профиль плотности задан двумя синусоидами, щели Кассини и Энке вырезаны по нормализованному радиусу. Цвет идёт от тёплого к белому по мере удаления.

### Остальное
- Пояс астероидов: 2 200 `InstancedMesh` из деформированных икосаэдров с дифференциальным вращением плюс 6 000 частиц пыли
- Пояс Койпера: 9 000 частиц с разбросом по наклонению
- Комета: эллипс с e = 0,72, ускоряется в перигелии, хвост из 900 частиц всегда направлен от Солнца
- Звёздное небо: три слоя, 12 000 звёзд, цвета по спектральным классам, полоса Млечного Пути
- Орбиты: эллипсы по уравнению `r = a(1 − e²) / (1 + e·cos θ)` с наклонением

## Управление

| Действие | Что делает |
|---|---|
| ЛКМ + тянуть | вращение камеры |
| ПКМ + тянуть | сдвиг |
| Колесо | зум |
| Клик по телу | перелёт и карточка с данными |
| `1`–`8` | перелёт к планете |
| `0` | Солнце |
| `Esc` | общий обзор |
| `F` | счётчик FPS |

## Технические заметки

**Освещение.** `PointLight` создаётся с `decay = 0` и `distance = 0`. С физически корректным затуханием по умолчанию яркость падает как `1/r²`, и на орбите Нептуна планета оказывается полностью чёрной.

**Постобработка.** ACES filmic tonemapping, экспозиция 1,05. Bloom с порогом 0,62 — Солнце выводит цвет с множителем 2,45 и уверенно проходит порог, планеты остаются ниже и не размываются.

**Производительность.** Генерация текстур разбита на задачи и выполняется по одной за тик, чтобы не блокировать поток. Матрицы астероидов обновляются одним проходом на кадр. Частицы Солнца и хвост кометы считаются на GPU.

## Запуск локально

```bash
git clone https://github.com/razorbladee/solar-system-3d.git
cd solar-system-3d
python3 -m http.server 8080
```

Открыть `http://localhost:8080`. Сборка не нужна: один HTML-файл, Three.js подтягивается через importmap с jsDelivr.
