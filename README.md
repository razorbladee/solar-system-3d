# ☀️ Интерактивная 3D карта Солнечной системы

Three.js + GLSL шейдеры + постпроцессинг. Всё в одном self-contained HTML файле.

**Живая демка:** https://razorbladee.github.io/solar-system-3d/

---

## ТЗ / Что реализовано

### Солнце
- Кастомный фрагментный шейдер на Simplex noise (6 октав FBM)
- Анимированная плазменная поверхность с 3 слоями шума, движущимися с разной скоростью
- Солнечные пятна (sunspots) через пороговый noise
- Пульсация яркости
- Двухслойная корона на Fresnel-эффекте с мерцанием (additive blending)
- PointLight в центре освещает все планеты

### Планеты (8 шт)
- Текстуры NASA / Solar System Scope (2K), с fallback на процедурные цвета при ошибке загрузки
- Реальные пропорции наклона оси, периодов обращения и вращения
- Земля: атмосферный glow на Fresnel-шейдере
- Сатурн: кольца из **15 000 частиц** с щелью Кассини и градиентом яркости

### Пояса
- **Пояс астероидов**: 4000 частиц между Марсом и Юпитером, медленное вращение
- **Пояс Койпера**: 3000 частиц за орбитой Нептуна

### Окружение
- Звёздное небо: 12 000 точек с реалистичным разбросом цветовых температур (голубые / жёлтые / белые)
- UnrealBloomPass для свечения Солнца и атмосфер
- ACES Filmic тонмаппинг

### Интерактив
- OrbitControls: вращение, зум, панорамирование (с инерцией)
- Raycasting: клик по планете → плавный подлёт камеры (ease-out quart) + инфопанель
- Инфопанель: диаметр, длина суток, длина года, температура, спутники, наклон оси, описание
- Слайдер скорости симуляции (0x — 5x)
- Переключатели орбит и подписей
- 2D HTML-лейблы, спроецированные на 3D координаты
- Кнопка сброса камеры

### UI
- Тёмная тема, OKLCH палитра, backdrop-filter
- Адаптив под мобилки

## Запуск локально

```bash
git clone https://github.com/razorbladee/solar-system-3d.git
cd solar-system-3d
python3 -m http.server 8000
```

Открыть http://localhost:8000

## Стек

- Three.js 0.162 (ES modules через importmap, CDN)
- OrbitControls, EffectComposer, UnrealBloomPass
- Кастомные GLSL вершинные и фрагментные шейдеры
- Никакой сборки, никаких зависимостей: один HTML файл
